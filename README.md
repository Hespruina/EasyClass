# EasyClass 课易

免费在线教学工具箱，提供统一账户系统、随机点名、投票计票、座位编排、任务统计与班级积分等课堂实用工具。无需安装，即开即用。

官网：https://easyclass.zhrhello.top/

## 产品组成

| 应用 | 说明 | 入口 |

## 功能特性

### EasyCore 易核（账户与数据）

- 标准 OIDC 单点登录（SSO），上游为 Keycloak，采用 Authorization Code + PKCE 流程
- 设备授权登录：未登录设备显示 6 位验证码（5 分钟有效），在另一台已登录设备的控制台输入即可完成登录，无需重输密码
- 会话 Cookie 有效期 90 天，支持多设备登录与统一登出
- 游客模式：免注册即可使用，会话 30 天，登录后可将游客数据合并到正式账号（冲突名单逐条选择处理策略）
- 云端名单管理：每人最多 50 个名单，每名单最多 1000 人，支持增删改查、分享、拼音排序
- 合并名单：把两份云名单合并成一份，按姓名自动去重；绑定了被合并名单的座位表 / 积分表 / 小组包 / 计票 / 任务自动改挂到合并后的名单，随后删除被合并的那份
- 名单是唯一事实来源：改完名单后，绑定它的积分表（严格对应名单）、计票与任务（名单同步、票数/进度按姓名保留）立即对齐，已打开的页面实时刷新
- 名单分享 Token：一次性的云端名单提取与选择接口
- 子用户：正式账号可为"不会操作的老师"创建凭用户名/密码登录的子用户，随时分配（或收回）名单 / 座位表 / 小组包 / 积分表四类访问权；子用户对被授权对象的变更直接同步到主用户（含积分实时同步，主用户与子用户打开同一张积分表时同处一个广播房间），子用户自建的对象仅主用户只读可见；主用户可随时改子用户密码（改毕踢全部会话）；子用户不能再创建子用户，其余能力与正式用户一致
- forteachers 数据导入：手动访问 `/easycore/import`（站内不放入口），用 forteachers.top 账号登录后，服务端代为读取并列出全部班级，可选择性导入名单（班级）、小组与组长职位、座位表、积分表与积分历史；积分支持不抵扣 / 1:1 抵扣 / 自定义比例三种口径
- 小组包：按名单建组（一人一组、拼音排序），或直接由 EasySeats 座位表的划分自动生成；小组总览与成员管理里右键成员名字即可设置职位（组长 / 副组长 / 课代表 / 自定义），自动生成的小组会把职位写回座位表，两处显示始终一致

### 易点名 Randamer

- 6 位遥控码机制：电脑端生成遥控码，手机端扫码或输码即可远程控制
- WebSocket 实时双向通信（gevent + flask-sock），低延迟同步点名结果
- 自定义名单：手动录入、扫码上传、云端名单同步
- 点名前缀自定义（系统默认前缀 + 用户自定义前缀 + 屏蔽前缀）
- 动画点名效果、历史记录、断线自动重连、遥控码过期自动刷新

### 易计票 EasyCounter

- 多计票任务：进入即任务列表（名称 / 已投票数 / 创建·修改时间），支持编辑信息、导出结果、删除
- 新建任务可命名（默认按日期「11月24日 计票2」），名单支持手动输入与选择云端名单
- 选择云端名单创建即**跟随**该名单：名单增删人后这次计票自动同步，已投出的票按姓名保留（控制台也可随时换绑或解绑）
- 纯云端模式：不再使用浏览器本地保存，名单与票数全部存 `counter.db`，每个操作即时落库
- WebSocket 实时同步（5s 心跳）：同一账号多端打开同一个计票，进度与全部数据实时一致
- 实时投票统计、票数自动排名；多候选人管理（批量添加、搜索、名称标签）
- 海报生成与导出（Excel / 海报）、多主题切换
- 游客可直接使用，登录正式账号时计票任务随其它游客数据一并迁移

### 易排座 EasySeats

- 单文件画布编辑器，鼠标与触屏双端操作（框选批量建座、拖拽移动座位、双指平移缩放）
- 座位格局与排座结果分离存储，支持自定义分组、组内改名、未分组总览
- 一键铺座、全班随机、组内随机排座（组内随机不跨组，空位按组轮转补齐）
- 手动排座：点座位选人、与同学换座、移出座位
- 职位气泡：可给任意学生设置职位（组长 / 副组长 / 课代表 / 自定义），显示在姓名上方；排座模式下右键学生即可设置，职位跟着人走，换座不丢
- 拖动换位：排座位模式下把学生直接拖到另一个座位松手即互换，拖到空座则直接移过去
- 允许空座：座位数可以多于名单人数，多出来的座位留空（可切换为「仅满座」严格模式）
- 座位表云端保存（游客可用），格局改动后自动裁剪失效排座结果，座位数满足名单人数校验

### 易任务 EasyTasks

- 多任务管理：任务列表展示任务总量、全部完成任务数、完成所有任务学生数、未完成任何任务学生数
- 进度最快 / 最慢学生 Top5，任务卡下方显示全体学生的平均完成进度条
- 纯云端模式：任务状态存 `tasks.db`，每个操作即时落库，WebSocket 多端实时同步
- 无极进度（0–100%）与五星评分相互独立，进度拉满即视为完成
- 绑定云名单：名单增删人后任务自动同步，进度与星级按姓名保留；控制台可换绑 / 解绑
- 学生卡片：未完成显示进度，已完成显示星级；点击卡片打开弹窗拖动进度条、点亮星级
- 完成情况总览：已完成 / 进行中 / 未完成三组名单，支持拼音首字母快速查找
- 游客可直接使用，登录正式账号时任务随其它游客数据一并迁移

### 易积分 EasyScore

- 绑定云名单：一张积分表对应一个班级，**名单始终与云名单完全一致**（不存快照）——名单加人即以初始分入表、名单删人则移出（本周期流水一并清除，归档历史保留）；forteachers 导入的积分表同样跟随
- 换绑名单：控制台编辑积分表即可改绑另一份云名单，学生按姓名重新对应，仍在名单里的保留积分
- 加分与扣分是两个独立的整数池，**永远分列累计、不合成净分**；总览里正负分明
- 自动抵消三档：不抵消 / 1 分加分抵 1 分扣分（direct）/ 自定义比例（如 2 分加分抵 2 分扣分，两池各自攒够才对冲）；抵消在加分、扣分落库的同一条写事务内即时执行并记一条 offset 流水
- 按期归档：支持「立即归档」与按周期自动归档（周期边界含农历计算）；**归档不停用积分表** —— 快照入档后余额回初始分、清空当前流水，直接进入新周期
- 归档快照可「分支」出一张新积分表；也可手动重置当前周期（丢弃、不落归档）
- 数据总览：人均正分 / 负分、两张 Top10、全体总表；历史记录按时间段分页，理由库账号级共享可复用
- 纯云端模式：全部存 `score.db`，WebSocket 多端实时同步（5s 心跳）
- 游客可直接使用，登录正式账号时积分表随其它游客数据一并迁移（冲突改名加"（游客）"后缀）；子用户可被主用户单独授权某张积分表的写权限

## 游客数据合并

游客免注册使用期间产生的数据（名单、座位表、前缀、**计票任务**、**学习任务**、**积分表**），在登录正式账号后可合并：

1. SSO 登录回调检测到旧游客会话，写入待合并凭证 Cookie
2. 访问合并确认页，冲突名单逐条选择策略：

| 策略 | 行为 |
|------|------|
| keep_both | 共存，游客版本重命名加"（游客）"后缀 |
| keep_mine | 保留账号内版本，丢弃游客版本 |
| keep_guest | 保留游客版本，覆盖账号内版本 |
| merge_all | 混合所有名字，去重合并 |

3. 确认合并后删除游客账号；游客直接登出或拒绝合并则立即删除游客数据
