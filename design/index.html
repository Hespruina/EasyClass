02

设计原则

八条约束，用来在没有人审核时也能做出与现有一致的决定。设计上下文：使用者是教师在课堂大屏上操作、学生在手机端遥控；场景是点名、排座、计票；气质是冷静可信的工具，带一点课堂的活泼——活泼只出现在舞台层。

01 · 单一强调色

全局只有 #45f3ff 一种强调色，且只用于当前项 / 主操作 / 链接 / 焦点 / 数值标注。其余层次一律靠石板灰的明度差与 1px 描边表达。青色铺满边框、阴影、文字就是"AI 味"的起点。

02 · 唯一焦点

一屏一个主按钮、一个当前导航项。点名框把这条做到极致：恒定 380×420，只装标题 + 姓名框 + 开始/停止，筛选条件一律放到右侧独立面板，条件增减永不影响框内留白。

03 · 实色与描边表达层级

层级 = 背景明度（#0f1419 → #161d24 → #1c242d → #232e39）+ 1px 中性描边。不用毛玻璃、不用任何发光光晕散色光效（彩色 glow、text-shadow 发光、模糊光晕、radial 散色一概禁止）、不用卡片套卡片。悬停上浮只允许中性黑阴影；圆角一律小圆角（4 / 8 / 16）。

04 · 动效只表达因果

动画解释层级、顺序、因果：谁先出现、谁从哪来、状态怎么变。不做常驻循环装饰。状态切换 150–300ms，统一 cubic-bezier(.16,1,.3,1)，并尊重 prefers-reduced-motion。

05 · 内容决定容器，不是反过来

面板高度随内容自适应（.filter-panel 垂直居中、上下等量扩展），绝不为了"对齐"给容器写死高度再裁内容。点名框的 420px 是唯一被允许的恒定容器，因为它承载的是一次性展示，不是列表。

06 · 品牌字只上舞台

ZCOOL KuaiLe / ZCOOL QingKe HuangYou 只用于点名框标题、姓名、品牌字标、小组标签、状态栏提示词。控制台与所有数据密集界面一律 Noto Sans SC 分级字重。

07 · 令牌不硬编码

颜色一律 var(--accent) / var(--male) / var(--danger)。参考层 2026-11-14 的真实事故：令牌定义了却没被 CSS 用，浅色模式整片仍是暗色霓虹。定义了就要用，改了就要全链路验。

08 · 小圆角 + 零发光

本项目偏好小圆角：控件 4px、容器 8px、模态 16px（详见 07 章），此前开发未注意，后续必须遵守。禁止一切发光光晕散色光效——彩色 glow、发光 text-shadow、模糊光晕、radial 散色背景、毛玻璃，因为这样显得很 AI（详见 12 章）。

验收问题：AI Slop Test

把界面给别人看，说"这是 AI 做的"，对方会立刻相信吗？若会，就是失败。本项目靠三件事避开：石板灰而非紫蓝渐变、零发光光晕、4 / 8px 小圆角而非大圆角卡片墙、中文品牌字与发丝线编号的数据手册感。

为什么它是最高基准

① 恒定性。框内永远只有三个元素，不因功能增加而变形。演进史是一条不断做减法的路：框内加筛选行 → 按内容加高 500px（错）→ 固定 450px + 控件贴底（用户否：中间空一大截）→ 最终独立面板。

② 焦点纯度。抽选时全屏只有一个在动的姓名，旋转描边与呼吸把它框住；其它控件全部退到暗处。这是"唯一焦点"最完整的实现。

③ 色与字的原点。#45f3ff 三态、ZCOOL 双展示字、深色石板底，都是从这里扩散到门户、排座工具页与参考层的。

应当新增抽选条件一律进 .filter-panel 的 .filter-section；区块间分隔线靠相邻选择器自动出现/消失；窄屏 @media(max-width:700px) 让面板落到框下方一列。
禁止往 .neirongquyu 加任何第四行；禁止把 420px 改成按内容自适应；禁止把旋转描边/呼吸搬到普通卡片。
