# EasyClass 课易

免费在线教学工具箱，提供统一账户系统、随机点名、投票计票等课堂实用工具。无需安装，即开即用。

官网：https://easyclass.zhrhello.top/

## 产品组成

| 应用 | 说明 | 入口 |
|------|------|------|
| EasyCore 易核 | 核心账户系统，提供统一用户认证、云端名单管理与数据同步 | https://easyclass.zhrhello.top/easycore/ |
| 易点名 Randamer | 随机点名工具，支持电脑端与手机端远程遥控 | https://easyclass.zhrhello.top/randamer/ |
| 易计票 EasyCounter | 投票计票工具，支持实时统计与自动排名 | https://easyclass.zhrhello.top/easycounter/ |
| 易排座 EasySeats | 教室座位编排工具，支持格局编辑、小组划分与随机排座 | https://easyclass.zhrhello.top/easyseats/ |

## 功能特性

### EasyCore 易核（账户与数据）

- 标准 OIDC 单点登录（SSO），上游为 Keycloak，采用 Authorization Code + PKCE 流程
- 会话 Cookie 有效期 90 天，支持多设备登录与统一登出
- 游客模式：免注册即可使用，会话 30 天，登录后可将游客数据合并到正式账号（冲突名单逐条选择处理策略）
- 云端名单管理：每人最多 50 个名单，每名单最多 1000 人，支持增删改查、分享、拼音排序
- 名单分享 Token：一次性的云端名单提取与选择接口

### 易点名 Randamer

- 6 位遥控码机制：电脑端生成遥控码，手机端扫码或输码即可远程控制
- WebSocket 实时双向通信（gevent + flask-sock），低延迟同步点名结果
- 自定义名单：手动录入、扫码上传、云端名单同步
- 点名前缀自定义（系统默认前缀 + 用户自定义前缀 + 屏蔽前缀）
- 动画点名效果、历史记录、断线自动重连、遥控码过期自动刷新

### 易计票 EasyCounter

- 实时投票统计、票数自动排名
- 多候选人管理：批量添加、搜索、名称标签
- 海报生成与导出、多主题切换
- 账号登录后云端同步数据

### 易排座 EasySeats

- 单文件画布编辑器，鼠标与触屏双端操作（框选批量建座、拖拽移动座位、双指平移缩放）
- 座位格局与排座结果分离存储，支持自定义分组、组内改名、未分组总览
- 一键铺座、全班随机、组内随机排座（组内随机不跨组，空位按组轮转补齐）
- 手动排座：点座位选人、与同学换座、移出座位
- 座位表云端保存（游客可用），格局改动后自动裁剪失效排座结果，座位数与名单人数一致性校验

## 游客数据合并

游客免注册使用期间产生的名单，在登录正式账号后可合并：

1. SSO 登录回调检测到旧游客会话，写入待合并凭证 Cookie
2. 访问合并确认页，冲突名单逐条选择策略：

| 策略 | 行为 |
|------|------|
| keep_both | 共存，游客版本重命名加"（游客）"后缀 |
| keep_mine | 保留账号内版本，丢弃游客版本 |
| keep_guest | 保留游客版本，覆盖账号内版本 |
| merge_all | 混合所有名字，去重合并 |

3. 确认合并后删除游客账号；游客直接登出或拒绝合并则立即删除游客数据
